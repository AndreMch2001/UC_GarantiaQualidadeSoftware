# Garantia da Qualidade de Software

Repositório acadêmico da disciplina **Garantia da Qualidade de Software** (Unisociesc), destinado ao armazenamento dos trabalhos e atividades práticas solicitados pelo professor.

Cada trabalho ou atividade fica em sua própria pasta, com o material, código e documentação correspondentes.

## Objetivo

Centralizar e versionar as entregas da disciplina, mantendo o histórico de evolução de cada atividade e facilitando a organização e a consulta do conteúdo ao longo do semestre.

## Estrutura do repositório

```
UC_GarantiaQualidadeSoftware/
├── README.MD
└── <NomeDaAtividade>/     # Uma pasta por trabalho ou atividade
```

Novas pastas serão adicionadas conforme as atividades forem passadas em aula.

## Atividades

| Pasta | Descrição |
| ----- | --------- |
| [LaboratorioTestes](./LaboratorioTestes) | Laboratório de testes de software |

## Como navegar

1. Abra a pasta da atividade desejada.
2. Consulte o `README` interno (quando existir) para detalhes de execução, requisitos e documentação.
3. Use o histórico do Git para acompanhar as alterações de cada entrega.
